# Claude Editor — инструкция

Редактор кода (PHP, JS/TS, Python, HTML/CSS, SQL…) в стиле PhpStorm, где главное — работа с несколькими чатами Claude Code.

## Запуск

| Что | Команда |
|---|---|
| Запуск из исходников | `npm install`, затем `npm start` |
| Обновить установленную версию (ярлык на рабочем столе) | `npm run install-local` — можно при открытом редакторе: он покажет кнопку «⬆ Новая версия — перезапустить» |
| Portable `.exe` для Windows | `npm run dist` → `release/Claude Editor <версия>.exe` (без установки) |

Нужен установленный **Claude Code** (`claude`), в который вы вошли. Если вход не выполнен, на верхней панели есть кнопка
**«Войти в Claude»**: она запускает `claude auth login`, вход идёт через claude.ai в браузере, ключ API не нужен.

Данные редактора (открытые проекты, избранное, прочитанные чаты, деплои, тесты) хранятся в `%APPDATA%\claude-editor`.
У portable-версии — в папке `claude-editor-data` рядом с `.exe`.

## Верхняя панель

Справа — аккаунт Claude: клик по почте — сменить аккаунт (claude.ai / Console / SSO), обновить статус, выйти.
Вход общий с Claude Code в терминале и IDE.

Кнопки показывают и прячут блоки: **Настройка, Проекты, ИИ-чат, Ошибки, Пинг, Деплои, Тесты, Ключи, Кеш ИИ**. Видимость каждого блока сохраняется.

- В скрытом блоке появилась проблема → его кнопка **пульсирует красным** и показывает счётчик.
- Открытый блок с проблемой → красный заголовок и кнопка «N проблем · прочитано ✓».
- Синий счётчик на «ИИ-чат» — сколько чатов закончили работу, а вы ещё не прочитали ответ.
- **Лимиты Claude** справа: «Сессия» (5-часовое окно) и «Неделя». Полоска и число — сколько израсходовано.
  Наведите — точные проценты, время сброса, недельные лимиты по моделям. Клик — обновить.

## Что запоминается

Открытые чаты, файлы и активная вкладка, раскрытые папки дерева, раскладка и размеры блоков, положение и размер окна,
модель/качество/автоодобрение/удалённое управление каждого чата.

## Раскладка и размеры блоков

- Проекты, ИИ-чат и Редактор ставятся в любую колонку: тяните за **⇄** в заголовке блока на другую колонку
  или нажмите ⇄ и выберите место. Центральная колонка всегда забирает всё свободное место.
- «Раскладка ▾» на верхней панели: «Код в центре», «**Чат в центре**», «Чат слева».
- Нижние блоки (Ошибки, Настройка, Пинг…) тянутся по высоте почти на весь экран, а между собой — по ширине.
  **⤢** (или двойной клик по заголовку) разворачивает их на всю центральную часть.

## Настройка (что сделать сейчас)

Живой чек-лист: вход в Claude, режим новых чатов, проекты, продакшен-домены, доступ к CI, сайты деплоя, тесты, ключи, место на диске.
Оранжевое «!» — настроить сейчас, прямо в строке. «✓» — готово. «i» — для сведения.
«Не нужно» убирает пункт из дел. Пока есть несделанное, у кнопки «Настройка» есть оранжевый счётчик.

## Настройки проекта

⚙ у проекта в дереве (или ПКМ → «Настройки проекта…»):
- название;
- **продакшен-домены и серверы** для блока «Пинг»: `https://site.ru` — HTTP и срок SSL, `host:port` — TCP, IP или хост — ping;
- интервал проверки (1–60 минут);
- сайт, который обновляется после `git push` (блок «Деплои»).

## Пинг

Все продакшен-адреса проверяются по расписанию. Не ответил 2 раза подряд — запись в «Ошибки» и красная кнопка «Пинг».
Когда сервер ожил, запись снимается сама. Истекающий меньше чем через 14 дней SSL — тоже проблема.
Полоски справа — последние 30 проверок.

## Группы проектов

Вкладки над деревом. Группа — набор связанных проектов с их открытыми чатами, избранным и файлами.
Клик — переключить группу (всё меняется разом), «＋» — новая группа, двойной клик — переименовать, ПКМ — удалить.
Работающие чаты другой группы продолжают работать в фоне.

## Проекты и избранное

- «＋» — открыть одну или несколько папок. Все проекты видны одним деревом.
- Вкладка **Избранное** — ПКМ по папке или файлу → «В избранное ★».
- ПКМ: вставить путь в чат, копировать путь, показать в проводнике, «Чаты этого проекта», убрать проект из списка.
- **Ctrl+V в дереве**: выделите папку и вставьте файлы, скопированные в проводнике (копируются, без перезаписи),
  или скриншот (сохранится как «Скриншот <дата>.png»). То же — ПКМ → «Вставить из буфера».
- **Сортировка**: ПКМ по папке → по имени, дате изменения, размеру или типу, ↑/↓. Запоминается для папки;
  можно сделать сортировкой по умолчанию для всех. Папки всегда сверху.
- Открытие: текст — в редакторе, картинки — в просмотрщике с кнопкой «Редактировать в Paint»,
  остальное (pdf, docx, xlsx, zip…) — в системной программе.
- Файл из дерева можно перетащить в поле вопроса — он прикрепится.

## Чаты Claude

- Чаты работают на движке Claude Code: та же подписка, настройки, CLAUDE.md и **общая память проекта**.
  История каждого чата лежит в `~/.claude/projects/…`, поэтому видны и чаты из PhpStorm или терминала.
- **Несколько чатов одновременно**: «＋ Чат» в выбранном проекте. Каждый работает в своём процессе и не забывает историю после перезапуска.
- **История ▾** — все чаты проекта с поиском. ✎ или двойной клик по вкладке — переименовать
  (имя сохраняется в Claude Code и видно в `claude --resume`).
- **Гармошка**: каждый вопрос — строка с датой и длительностью ответа. ⊞/⊟ — раскрыть или свернуть все, сверху поиск.
- **✎ N файлов** у ответа — сколько файлов изменено; клик открывает вкладку «Файлы» внутри ответа (число замен, время, клик по файлу открывает его).
- Пути в ответах (`src/app.php:42`) кликабельны и открываются в редакторе.
- Вкладки внизу чата: **Чат**, **Файлы** (все изменённые файлы, по дате последнего изменения, с переходом к ответу), **Деплои**,
  **Разрешения** (журнал одобрений).
- Индикаторы: крутится — работает; оранжевый «!» — ждёт разрешения или ответа на вопрос; синяя точка — готово, не прочитано; красная — ошибка.
- Под полем ввода:
  - **Модель** — Fable, Opus, Sonnet, Haiku (или по умолчанию);
  - **Качество** — от «Быстро» до «Максимум» (сколько модель думает);
  - **Режим разрешений** — как в настройках Claude, Спрашивать, Правки без вопросов, Авто, План, Без ограничений.

  Модель и качество запоминаются для каждого чата и меняются на лету.
- **⚡ Подтверждать всё** (галочка под полем ввода, переключатель во вкладке «🛡 Разрешения» или кнопка «⚡ Разрешать всё в этом чате» на карточке запроса) — одобряет каждый запрос, в отличие от режимов в выпадающем списке — все запросы разрешений одобряются сами. Каждое решение (и ваши клики) пишется во вкладку
  «🛡 Разрешения» и в `approvals.jsonl` в папке данных редактора. Вопросы ИИ к вам по-прежнему ждут ответа.
- **Вложения**: Ctrl+V в поле вопроса — скриншот или файлы из проводника; перетаскивание; 📎 — выбрать файл.
  Миниатюры видны в вопросе, в том числе в старых чатах из терминала. Клик — просмотрщик (←/→, Paint, копировать).
- **🪙 у ответа** — токены, потраченные на ответ; при наведении — разбивка (вход, выход, кеш) и стоимость.
- **/RC** (галочка под полем ввода или команда `/rc`) — Remote Control, как в Claude Code: чат появляется на claude.ai/code и в приложении Claude,
  писать можно и с телефона, и из редактора, всё видно в обоих местах. Внутри — скрытый интерактивный Claude (нужен Git for Windows).
  Подтверждения в этом режиме — с телефона или ⚡ Авто; картинки не прикрепить (только пути к файлам). После перезапуска редактора /RC выключен.
- **Вкладки внутри ответа** — вертикально справа: «Ответ», «✎ Файлы» (изменённые в этом ответе), «🛡 Разрешения» (что Claude спрашивал
  и как решено: ⚡ авто / ✓ вы / ✕ отклонено). Значки ✎ и 🛡 в заголовке вопроса открывают нужную вкладку.
- **Команды «/»**: наберите «/» — список команд редактора и сессии (команды Claude Code, скиллы). ↑/↓, Tab/Enter.
  `/status` — состояние чата (модель, режим, аккаунт, версия, MCP-серверы, контекст, лимиты), `/context` — только контекст.
  Остальные команды (`/compact`, `/review`, скиллы…) уходят в Claude Code.
- **Esc** или «■ Стоп» — прервать ответ.
- Вопрос, отправленный пока Claude отвечает, Claude Code обрабатывает вместе с текущим — такие вопросы показываются **одним блоком**
  с общим ответом (в заголовке «+N вопросов»).
- Черновик (текст и вложения) хранится для каждого чата отдельно и не пропадает при переключении чатов и перезапуске.
- После отправки вопроса чат прокручивается в конец и держится внизу, пока идёт ответ (если вы сами не прокрутили вверх).

## Ошибки

Сюда попадают: ошибки чатов и лимиты Claude, упавшие или зависшие деплои, непройденные тесты, просроченные ключи,
а также то, о чём сообщил сам ИИ. Ссылки ведут к чату или файлу.

## Ключи

- Сверху — **где ищу**: шаблоны путей относительно каждого проекта (редактируются кнопкой «Шаблоны путей ✎») и список просканированных файлов.
- Срок действия определяется так: JWT — по `exp`, сертификат PEM — по дате окончания, токен GitHub — запросом к GitHub,
  любой ключ — по дате в той же или соседней строке (`expires 2026-12-01`, `действует до 01.12.2026`).
- Статусы: просрочен, истекает (меньше 14 дней), действует, недействителен, срок неизвестен.
- Значения ключей целиком не показываются. Сканирование — при запуске, раз в час и по кнопке.

## Деплои

1. Редактор следит за git-репозиториями проектов и тех, где чаты правили файлы.
2. После `git push` (сдвинулась remote-ветка, а коммит есть локально) появляется запись. Она привязывается к чату, который делал push.
3. Этапы: **Push → CI → Сайт → Тесты**.
   - CI — check runs GitHub (Actions). Для приватных репозиториев: токен в «⚙ Сайты и доступ»
     или галочка «брать учётные данные из git».
   - Сайт — URL на репозиторий. Режим «изменение страницы» (меняются JS/CSS-бандлы, ETag или содержимое)
     или «хэш коммита на странице».
   - Если за 30 минут сайт не обновился — «Завис» и запись в «Ошибки».

## Тесты

Smoke-тесты по URL: ожидаемый код ответа, обязательный текст, максимальное время. Запускаются после каждого успешного
деплоя и вручную «▶ Запустить». Упавший тест подсвечивает кнопку «Тесты» и попадает в «Ошибки».

## Кеш ИИ

Сколько файлов Claude насоздавал на системном диске и сколько можно удалить, по категориям:

| Категория | Чистить |
|---|---|
| Временные файлы ИИ (`%TEMP%\claude`, scratchpad) | безопасно |
| Служебные данные сессий (субагенты, большие выводы) | безопасно |
| История чатов (транскрипты) | осторожно: старые чаты пропадут |
| Резервные копии правок (`file-history`) | безопасно |
| Снимки shell, вставки, загрузки, логи | безопасно |
| Кеш Claude Desktop | безопасно, лучше при закрытом Desktop |
| Старые версии Claude Code (~280 МБ каждая) | безопасно, текущая остаётся |

- Мусор — файлы старше выбранного срока: по умолчанию 7 дней, для чатов — 60.
- Никогда не удаляются: файлы моложе суток, открытые и работающие чаты, память проекта.
- Каждое удаление подтверждается. Список «Самые большие» позволяет удалить отдельный файл.
- Блок подсвечивается, если диск занят больше чем на 90% или накопилось больше 1 ГБ мусора.

## Что умеет ИИ в редакторе

В каждый чат подключён MCP-сервер `editor`, а в системный промпт добавлена инструкция о блоках. ИИ сам:

| Инструмент | Что делает |
|---|---|
| `report_problem` / `resolve_problem` | сообщает о важной проблеме в «Ошибки» и снимает её |
| `set_deploy_target` | привязывает сайт к репозиторию |
| `add_smoke_test`, `run_tests` | заводит и запускает тесты |
| `add_key_pattern` | добавляет место хранения ключей |
| `add_prod_domain` | добавляет прод-домен или сервер в «Пинг» |
| `open_file` | открывает у вас файл на нужной строке |
| `get_editor_state` | читает состояние блоков (деплои, тесты, проблемы) |

## Горячие клавиши

| Клавиши | Действие |
|---|---|
| Ctrl+S | сохранить файл |
| Ctrl+F | поиск в файле |
| Enter / Shift+Enter | отправить вопрос / новая строка |
| Esc | остановить ответ |
| Средняя кнопка мыши по вкладке файла или чата | закрыть вкладку |
| «»N» в конце строки вкладок | список вкладок, которые не поместились; колесо мыши над вкладками — прокрутка |
| F12 | инструменты разработчика |

## Разработка

```
src/main/       Electron main: claude.ts (чаты через Agent SDK), transcript.ts (разбор истории),
                deploy.ts (пуши/CI/сайт/тесты), keys.ts (сканер ключей), editor-mcp.ts (инструменты для ИИ)
src/renderer/   React UI: App.tsx (верхняя панель, раскладка), components/*
scripts/smoke.mjs  запуск приложения через Playwright со скриншотами: node scripts/smoke.mjs <папка> [шаги.mjs]
```
